In Apache Spark, Deploy Mode decides where the Driver program runs.

There are 2 deploy modes:

1️⃣ Client Mode
2️⃣ Cluster Mode

# 1️⃣ Client Mode

👉 What happens?

Driver runs on your local machine (or edge node).

Executors run inside the cluster.

<img width="475" height="260" alt="image" src="https://github.com/user-attachments/assets/703779b9-7552-4521-9a91-2be3d3e2469d" />

**🔎 Characteristics**

Driver logs appear in your terminal.

If your machine disconnects → job fails ❌

Good for debugging & development.

**🎯 When to Use?**

Testing

Small jobs

Interactive sessions

# 2️⃣ Cluster Mode

👉 What happens?

Driver runs inside the cluster.

Executors also run inside the cluster.

<img width="472" height="255" alt="image" src="https://github.com/user-attachments/assets/db46a453-b7bb-4b9d-8cf8-d0ec91cde019" />

**🔎 Characteristics**

Driver runs on worker node.

Your local machine can disconnect → job continues ✅

Better for production workloads.

**🎯 When to Use?**

Production jobs

Long-running ETL pipelines

Scheduled workflows
